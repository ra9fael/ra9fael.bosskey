# 透明透镜实测：桌面之上的黑洞

`boss h`（`--cover blackhole`）的封面窗口是**透明**的：桌面从窗口透出，被引力透镜
扭曲后显示。截图来自 `QScreen::grabWindow(0, …)` 在封面仍隐藏时抓取的快照——窗口
显示后再抓会把封面自己录进去，形成反馈。

## 画面

`desktop-lens.png`：全屏 1920×1080 实拍（存盘时缩到 1280×720、256 色以遵守
证据体积约定，内容无裁切）。桌面内容（WorkBuddy 侧栏、浏览器窗口里的中文页面）
绕洞弯成弧线、文字沿弧线拉伸，阴影中心纯黑吞掉桌面，金色吸积盘压在最前；
角落处透镜效应淡出，原始桌面无接缝地透出。

## 关键事实

| 项目 | 数值 | 说明 |
|---|---|---|
| 桌面快照抓取 | 全屏 **37 ms**、480×270 窗口 6 ms | `grabWindow` 在窗口仍隐藏时调用，避免自录反馈；只对 blackhole 场景抓，其余场景保持秒开 |
| 私有提交 | 106 MB（工作集 86.1 MB） | 比不抓桌面的场景多 14 MB，正是 1920×1080 快照 |
| CPU | 2.3% 单核 | 30 fps `Timer` 驱动 |
| 退出序列 | 通过 | 透明窗口下键入 `deadbeef` 正常退出（`tools/verify/exit.py`，`focused=True`） |
| 其余四场景 | 不漏桌面 | bsod / update / gcc / matrix 在透明窗口下各自铺满不透明背景，逐一截图确认 |

「到 cover shown」耗时 blackhole 与 bsod 同处 0.49–0.70 s 区间（新进程启动噪声主导），
37 ms 的抓取不是秒开路径上的主导项。

## 落地要点

- 封面窗口 `color: "transparent"`；其余四个场景各自铺满不透明背景，不需要按场景切换窗口属性。
- D3D11 的透明合成按**预乘 alpha** 解释着色器输出：非预乘会让 alpha=0 的区域把颜色
  叠到桌面上，整片窗口染色。shader 输出 `vec4(col * alpha, alpha)`。
- 桌面快照经 image provider（`image://desktop/<epoch>/<screen index>`）进 QML，
  由不可见的 `Image` 作 `ShaderEffect` 采样源；epoch 只用于让 URL 变化触发重载。
- 星野已移除：桌面才是背景，星星浮在桌面上违和。`window` 位移衰减保留，保证与远场无缝。

已知未覆盖：多屏未实测（本机只枚举到一块显示器）；桌面为静态快照，不跟随桌面实时变化。
