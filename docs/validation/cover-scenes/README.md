# 封面场景实测：D3D11 唯一后端 + 代码雨 / gcc 改动

本次把渲染后端收敛为 D3D11——软件光栅不渲染 `ShaderEffect`，见
[../shader-backend-probe](../shader-backend-probe)——并改了代码雨与 gcc 两个场景。
五个场景在 D3D11 下逐一截图确认过（蓝屏中文与二维码、更新 spinner、gcc 日志、
代码雨、黑洞）均正常，下面是两处改动的证据。

## 代码雨：中文 + 英文 + 片假名

`matrix.png`：同一列内混排半角片假名、数字、大小写拉丁字母与汉字；宽字符在格子内居中，
列距保持一致，不挤邻列。

## gcc：无限滚动 + 长行换行

同一次覆盖内的三帧（480×270 窗口，`--autohide 90`）：

| 时刻 | 截图 | 画面 |
|---|---|---|
| 6 s | `gcc-t6.png` | 第一趟编译后段，70%–76% |
| 51 s | `gcc-t51.png` | 第二趟，56%–64% |
| 71 s | `gcc-t71.png` | 第三趟，32%–42% |

百分比在一趟之内爬到 96% 就交棒给下一趟（CMake 重新生成），不链接、不出现 100%：
覆盖要挂多久都还有东西在滚。`gcc-wrap.png` 是换行特写：长路径与长警告在窗口边缘
换行，和真终端一样；警告行保持琥珀色。
