# 黑洞 Shader 场景实测

`boss h`（`--cover blackhole`）的实现：一个 `ShaderEffect` 场景，逐像素积分史瓦西测地线。
阴影、光子环、盘面上下双弧、被弯成弧线的星空都是积分结果，不是画出来的。
移植与坑位分析见 [../../blackhole-shader.md](../../blackhole-shader.md)。

环境：Windows 11，NVIDIA RTX 3080，显示 2560×1440@60Hz（当前会话为 1920×1080 逻辑分辨率，
GameViewer/Remote Display 虚拟显示），Qt 6.12.0 MSVC 2022 x64。

| 项目 | 原型 | 最终版 | 条件 |
|---|---|---|---|
| 私有提交 | 90.5 MB | **91.8 MB** | 全屏 1920×1080，D3D11，实时渲染 |
| 工作集 | 77 MB | 77.3 MB | 同上 |
| CPU | ≈ 0% 单核 | ≈ 0% 单核 | 计算在 GPU，CPU 只提交命令 |
| 帧间隔 | 31 ms（≈32 fps） | 31 ms（≈32 fps） | 480×270 窗口同为 31 ms，**与像素数无关，不是填充率瓶颈** |

原型与最终版的差别只在观感参数（色温 5500 K → 4200 K、gain 2.2 → 1.1、exposure 1.4 → 1.0）
和动画驱动（`NumberAnimation` 满帧 → 30 fps `Timer`）；内存与帧耗不变。

`blackhole-shader-scene.png` 是最终版全屏 1080p 画面。

已知未覆盖：

- 双屏/多屏未实测（本机当前只枚举到一块显示器）。`memoryMB` 取 1024 MB 已为此留出余量：
  参照本插件早前记录，D3D11 在双 2560×1440 下约 210 MB。
- 退出序列沿用 `BossCover` 的共用路径，未针对该场景单独回归（场景不碰按键处理）。
- 帧间隔上限来自本机虚拟显示管线，真实独显直连显示器上应能跑满 60 fps；30 fps 的
  `Timer` 上限因此在本机无法与显示管线的 31 ms 区分开。
